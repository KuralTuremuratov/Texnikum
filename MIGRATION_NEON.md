# Перенос базы в Neon

В проекте есть не только база: фронтенд сейчас обращается к Supabase Auth, REST API и Storage. Neon заменяет PostgreSQL, но не является drop-in заменой Supabase SDK. Поэтому нельзя вставить Neon connection string в `REACT_APP_SUPABASE_URL`: строка подключения к БД должна быть только на сервере, иначе пароль БД окажется доступен всем посетителям сайта.

## 1. Импорт таблиц и данных

1. Зарегистрируйтесь на [Neon](https://neon.com) и создайте проект PostgreSQL.
2. Откройте **SQL Editor** в Neon.
3. Откройте [database/neon-migration.sql](database/neon-migration.sql), скопируйте весь файл и выполните его в SQL Editor.
4. Проверьте результат:

```sql
SELECT * FROM public.course_schedules ORDER BY id;
SELECT * FROM public.teacher_schedules ORDER BY id;
SELECT * FROM public.gallery_images ORDER BY id;
```

Скрипт не удаляет таблицы и его можно безопасно запустить повторно. Он также добавляет `para5`, потому что фронтенд уже использует это поле, а в исходном `restore.sql` его не было.

## 2. Что нельзя импортировать из исходного SQL

Блоки `auth.users` и `auth.identities` относятся к внутренней схеме Supabase. В Neon такой схемы нет; их запуск завершится ошибкой. Администратора нужно будет создать в выбранной системе авторизации заново.

Также одна запись галереи (`id = 7`) ссылается на файл в прежнем Supabase Storage. После отключения старого проекта эта картинка, вероятно, не загрузится. Локальные картинки `/01.jpg`–`/06.jpg` останутся в проекте; внешнюю картинку нужно загрузить снова в новое хранилище.

## 3. Подключение сайта

Для завершения переноса нужен небольшой серверный API между React и Neon, плюс отдельные Auth и Storage. Рекомендуемая бесплатная связка:

- Neon — PostgreSQL;
- серверный API на Vercel Functions или Cloudflare Workers;
- Cloudinary (или Cloudflare R2) — изображения;
- вход администратора — через серверный API с безопасным хешем пароля.

После создания проекта Neon передайте **только** строку подключения в защищённом способе (не добавляйте её в `.env` с префиксом `REACT_APP_` и не публикуйте в чат). Также укажите, где сейчас развёрнут сайт (Vercel, Netlify, GitHub Pages или другое). Тогда можно перенести код с Supabase на API и подключить его к Neon безопасно.
