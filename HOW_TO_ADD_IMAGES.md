# 📸 Как добавить изображения (logo.png и homepage_main.jpg)

## Быстрая инструкция

### Шаг 1: Подготовьте файлы

У вас должны быть 2 файла из приложенных изображений:
1. **logo.png** - новый логотип техникума (круглый синий логотип)
2. **homepage_main.jpg** - фото здания техникума

### Шаг 2: Скопируйте файлы

Откройте папку проекта `d:\Documents\texnikum` и выполните:

#### Вариант A: Через проводник Windows
1. Откройте папку `d:\Documents\texnikum\public`
2. Скопируйте `logo.png` в эту папку (перезапишите старый)
3. Скопируйте `homepage_main.jpg` в эту папку

#### Вариант B: Через PowerShell
```powershell
# Замените <путь-к-файлам> на реальный путь где находятся ваши изображения
cd d:\Documents\texnikum\public
Copy-Item "<путь-к-файлам>\logo.png" -Destination "logo.png" -Force
Copy-Item "<путь-к-файлам>\homepage_main.jpg" -Destination "homepage_main.jpg"
```

### Шаг 3: Проверьте что файлы на месте

```powershell
cd d:\Documents\texnikum\public
dir *.png, *.jpg
```

Вы должны увидеть:
- `logo.png` (новый файл)
- `homepage_main.jpg` (новый файл)

### Шаг 4: Запустите локальный сервер для проверки

```bash
npm start
```

Откройте http://localhost:3000 и проверьте:
- [ ] Новый логотип в Header
- [ ] Новое изображение на главной странице

### Шаг 5: Закоммитьте изменения

```bash
git add public/logo.png public/homepage_main.jpg
git commit -m "assets: add new logo and homepage image"
git push origin main
```

## Важные требования к изображениям

### logo.png
- **Формат**: PNG (с прозрачным фоном)
- **Рекомендуемый размер**: 200x200px или 512x512px
- **Максимальный размер файла**: 100 KB
- **Используется**: Header, Footer, favicon

### homepage_main.jpg
- **Формат**: JPG или JPEG
- **Рекомендуемый размер**: 1200x800px (соотношение 3:2)
- **Максимальный размер файла**: 500 KB
- **Используется**: Главная страница (Hero section)
- **Оптимизация**: Сжатие через TinyPNG или аналог

## Если изображения не отображаются

### Проблема: Старый логотип всё ещё виден
**Решение**: Очистите кеш браузера (Ctrl+Shift+Delete → Images and Files)

### Проблема: homepage_main.jpg показывает ошибку 404
**Решение**: 
1. Убедитесь что файл называется **точно** `homepage_main.jpg` (не `homepage-main.jpg`)
2. Проверьте что файл находится в `public/` (не в подпапке)

### Проблема: Изображения слишком большие/медленно грузятся
**Решение**: Оптимизируйте через:
- https://tinypng.com (для PNG)
- https://compressor.io (для JPG)

## Альтернатива: Использование временных изображений

Если у вас пока нет изображений, можно использовать временные:

### Для logo.png
Код уже поддерживает существующий `logo.png` в папке public.

### Для homepage_main.jpg
Переименуйте существующее изображение:
```powershell
cd d:\Documents\texnikum\public
Copy-Item "1.jpg" -Destination "homepage_main.jpg"
```

Потом замените на настоящее когда будет готово.
