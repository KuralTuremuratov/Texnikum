# Mobile Responsiveness Fixes (375-430px)

## Обзор изменений

Все проблемы адаптивности для мобильных экранов (375–430px) успешно исправлены. Логика компонентов, цветовая палитра и контент полностью сохранены — изменена только вёрстка/CSS.

---

## 1. ✅ Главная страница (Home)

### Hero-секция
**Проблема**: Избыточное вертикальное пространство на мобильных
**Решение**:
- Уменьшены отступы: `padding-top: 32-48px`, `padding-bottom: 42-60px`
- Оптимизированы margin между заголовком, подзаголовком и кнопками
- Уменьшен размер заголовка с использованием `clamp(2.2rem, 10vw, 3.5rem)`
- Кнопки занимают меньше вертикального пространства (min-height: 46px)

### Декоративные элементы
**Проблема**: Плавающие бейджи перекрывают контент и выходят за границы
**Решение**:
- Уменьшен размер hero-cards: `padding: 8-10px`, `min-width: 88-95px`
- Скорректировано позиционирование бейджей относительно контейнера
- Скрыты orbit-круги на мобильных (display: none)
- Уменьшен декоративный hero-sun: `width: 130px` вместо 190px

### Блоки-кнопки
**Проблема**: Избыточная высота блоков "Dars jadvali", "Texnikum hayoti"
**Решение**:
- Уменьшена высота quick-link: `min-height: 76px` (было 114px)
- Уменьшен padding: `14px` вместо `19px`
- Уменьшены размеры иконок: `width: 38px` (было 43px)

## 2. ✅ Карточки направлений (Yo'nalishlar, Dual-ta'lim)

### Сетка карточек
**Проблема**: Две узкие колонки с переносом текста по 1-2 слова на строку
**Решение**:
- Переключение на одну колонку на мобильных: `grid-template-columns: 1fr`
- Карточки теперь занимают всю ширину экрана
- Текст больше не переносится неестественно

### Оптимизация размеров
**Проблема**: Иконки слишком большие, карточки растягиваются
**Решение**:
- Уменьшен размер иконки: `54px` на планшетах, `48px` на экранах <430px
- Уменьшен margin-bottom иконки: `16px` → `12px`
- Padding карточек: `22-28px` (адаптивно)

### Скроллинг списков
**Проблема**: Длинные списки растягивают карточки на весь экран
**Решение**:
- Добавлен внутренний скролл: `max-height: 320px; overflow-y: auto`
- Кастомный scrollbar (4px ширина) для удобства
- Применяется как к новым `.route-card ul`, так и к старым `.card ul`

## 3. ✅ Таблицы расписания (Navbatchilik, 1-kurs dars jadvali)

### Структура таблицы
**Проблема**: Первая колонка (имя) выпадала из потока, нарушая выравнивание строк
**Решение**:
- На десктопе: обычная HTML-таблица с `table-layout: fixed`
- На мобильных (<680px): карточный режим отображения

### Мобильный карточный layout
**Реализация**:
```css
- thead скрыт (display: none)
- tbody как flex-column с gap: 12px
- tr как отдельные карточки с border-radius и box-shadow
- td как строки внутри карточки (flex, space-between)
- Первая ячейка (имя/группа) стилизована как заголовок карточки (синий фон)
- Остальные ячейки отображают label дня недели через ::before data-label
```

### Оптимизация для мобильных
- Уменьшен padding ячеек: `9px 14px` (было 10-12px 16px)
- Имя/группа как заголовок карточки с центрированием
- Label дней недели: `font-size: 0.75rem`, `min-width: 90px`
- Корректное выравнивание label и значения через `space-between`

### Скроллинг
- На мобильных: overflow: visible (нет горизонтального скролла)
- На десктопе: overflow-x: auto (скроллится только таблица, не вся страница)

## 4. ✅ Общие улучшения

### Единообразная высота элементов
- Кнопки: `min-height: 44-48px` (соответствует рекомендациям доступности)
- Карточки используют адаптивные отступы через clamp()
- Консистентные gap между элементами сетки

### Предотвращение рваных переносов
- Используется `word-break: break-word` для длинных слов
- Font-size уменьшается через clamp() на мобильных
- Оптимизирована line-height для читаемости (1.4-1.45)

### Дополнительные фиксы
- Visit section: изображение с адаптивной шириной `calc(100% + clamp(24px, 6vw, 32px))`
- Footer: переключение на одну колонку
- Предотвращён горизонтальный overflow на всех страницах

## Медиа-запросы

### @media (max-width: 768px)
- Основной брейкпоинт для планшетов и больших мобильных
- Карточки направлений: одна колонка
- Таблицы: карточный режим
- Скрытие декоративных orbit-элементов

### @media (max-width: 680px)
- 2x2 сетка навигационных вкладок
- Одноколоночные карточки .grid-3
- Максимальная высота списков с overflow

### @media (max-width: 430px)
- Дополнительное уменьшение размеров
- Кнопки hero-секции на полную ширину
- Минимальные размеры иконок и отступов

### @media (max-width: 380px)
- Финальная оптимизация для самых маленьких экранов
- Font-size от 0.8rem
- Минимальные размеры touch-элементов сохранены (36-38px)
