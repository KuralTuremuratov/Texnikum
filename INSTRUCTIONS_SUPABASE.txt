РУКОВОДСТВО: ЧТО ДЕЛАТЬ, ЕСЛИ SUPABASE ЗАМОРОЗИЛ ПРОЕКТ

СОХРАНИТЕ ЭТОТ ФАЙЛ НА БУДУЩЕЕ.

ШАГ 1: ВОССТАНОВЛЕНИЕ ДАННЫХ (НА САЙТЕ SUPABASE)
1. Зайдите в ваш "замороженный" (Paused) проект.
2. Нажмите кнопку "Restore" (Восстановить) -> "Restore to a new project" (если есть такая кнопка).
   - Если кнопки нет: Скачайте резервную копию "Database Backup" (выберите формат SQL, если доступен).
3. Создайте НОВЫЙ проект на Supabase (Dashboard -> New Project).
4. Если вы скачали SQL-файл:
   - Откройте его в Блокноте, скопируйте весь текст.
   - В новом проекте Supabase зайдите в "SQL Editor" -> "New Query".
   - Вставьте текст и нажмите "RUN".
   - (Если возникают ошибки с "role postgres", просто удалите эти строчки из начала файла).

ШАГ 2: СОЗДАНИЕ АДМИНА
1. В новом проекте Supabase зайдите в меню "Authentication" (значок человечков) -> Users.
2. Нажмите "Add User" -> "Create new user".
3. Введите Email (ваш) и НОВЫЙ Пароль.
4. Поставьте галочку "Auto Confirm User".
5. Нажмите "Create User".

ШАГ 3: ПОДКЛЮЧЕНИЕ САЙТА
1. В новом проекте Supabase зайдите в Settings (шестеренка) -> API.
2. Скопируйте:
   - Project URL
   - anon / public key
3. На компьютере откройте папку проекта и файл `.env`.
4. Замените старые значения на новые (URL и Key).
5. Сохраните файл.

ШАГ 4: ПРОВЕРКА И ОБНОВЛЕНИЕ (DEPLOY)
1. В терминале запустите: `npm start`
2. Проверьте, что сайт открывается локально (http://localhost:3000) и вы можете войти (с новым паролем!).
3. Чтобы обновить сайт в интернете:
   - Остановите сервер (Ctrl+C).
   - Запустите команду: `npm run build`
   - Дождитесь появления папки `build`.
   - Зайдите на app.netlify.com -> Ваш сайт -> Deploys.
   - Перетащите папку `build` в окошко обновления.

Готово! Сайт снова работает.
